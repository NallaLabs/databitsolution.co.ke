Partner logos
=============
1. Put each partner's official logo file in this folder. SVG is best; PNG works too.
2. In index.html, find the PARTNERS section and add the file name to that
   partner's data-logo attribute, for example:
       <li data-logo="hp.svg">HP</li>
3. Refresh the page. The name is replaced by the logo. If the file is missing,
   the name stays as text.

Logos show in greyscale and turn to full colour on hover.

Use the files from each brand's partner portal or press kit, and follow its
logo rules. Most brands only allow their logo on a reseller site if the company
is an authorised partner, so confirm Databit's status with each brand first.
