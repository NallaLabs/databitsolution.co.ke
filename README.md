# databitsolution.co.ke

Landing page for **Databit Solutions**, a Kenyan ICT consultancy supplying office/IT products and licensed software, plus IT services (software development, CCTV, cybersecurity, repairs, training).

## Structure
- `index.html` — single-page site
- `css/styles.css` — styles
- `js/` — page behaviour
- `assets/` — logo, favicons, fonts, product images

Static site: no build step. Open `index.html` in a browser, or deploy the folder to any static host.
